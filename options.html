LeetCode Sync

Accepted submissions on leetcode.com get pushed to your GitHub repo automatically.

How to create a token (2 minutes)
  1. Create a GitHub repo for your solutions, e.g. leetcode-solutions. Tick "Add a README".
  2. Open GitHub → Fine-grained tokens → Generate new token.
  3. Repository access: "Only select repositories" → pick your solutions repo.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Set an expiration, generate, and paste the token below.
